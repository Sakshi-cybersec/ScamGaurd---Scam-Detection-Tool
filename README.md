ScamGuard

A Rule-Based Social Engineering and Scam Detection Tool

ScamGuard is a lightweight, privacy-focused cybersecurity application designed to help users identify potentially fraudulent and socially engineered messages.

The application analyzes suspicious text for common scam indicators, including credential requests, psychological urgency, financial or prize bait, and embedded external links. Each detected threat indicator contributes to a cumulative risk score between 0 and 100, allowing users to quickly understand the potential severity of a message.

Key Features
🔍 Instant Risk Scoring — Generates a threat score from 0–100.
🚨 Threat Detection — Identifies urgency, credential-harvesting, financial bait, and suspicious-link indicators.
📊 Risk Categorization — Classifies messages as Low, Medium, or High Risk.
💡 Safety Recommendations — Provides actionable guidance based on the detected risk level.
🔒 Privacy-Centric — Runs offline without transmitting analyzed messages to external servers.
🖥️ Simple GUI — Built with Python and Tkinter for easy desktop use.
Technology Stack
Python 3
Tkinter — Graphical User Interface
Python re module — Regular-expression-based pattern matching
Risk Levels
Score	Risk Level

40–69	🟠 Medium Risk
70–100	🔴 High Risk

ScamGuard is designed as a lightweight first line of defense that helps users recognize common social-engineering patterns and make safer decisions when handling suspicious digital communications.
